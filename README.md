# PDF2PIC

PDF2PIC是一个基于网页的应用程序，允许用户将PDF文档转换为高质量的拼长图。

## 项目概述

PDF2PIC使用户能够通过简单的拖放操作上传PDF，并获得一张完整的长图，便于在社交媒体、消息应用或演示文稿中分享。

### 核心功能

- **PDF转长图**：将多页PDF文件拼接成单一长图
- **密码保护**：网站访问需要密码验证，密码状态本地缓存
- **尾部图片添加**：支持用户添加自定义图片作为拼长图的尾部
- **简单易用**：拖放上传，一键转换

## 技术栈

- **前端框架**：Next.js
- **CSS框架**：Tailwind 4.X CSS
- **部署平台**：Vercel
- **主要依赖**：
  - PDF解析：PDF.js
  - 图像处理：Canvas API

## 功能详细说明

### 1. 密码保护

- 访问网站需要输入正确密码
- 密码验证成功后状态保存在本地存储中
- 可自定义密码设置

### 2. PDF转换流程

- 用户将PDF拖入指定区域或通过上传按钮选择文件
- 系统**完全在客户端**处理PDF并进行转换，不依赖服务器处理能力
- 所有计算和渲染均在浏览器中进行，避免Vercel服务器负载和限制
- 转换过程显示进度条
- 生成预览并提供下载选项

### 3. 尾部图片添加

- 支持上传单页PDF作为尾部图片
- 用户选择的尾部图片会被缓存在本地存储中
- 再次访问网站时，之前使用的尾部图片会自动加载，无需重新上传
- 提供清除已缓存尾部图片的选项
- 系统将尾部图片附加到主PDF转换结果的末尾
- 生成包含尾部图片的最终预览

## 安全与隐私

- 所有文件处理在客户端完成，不存储用户上传的PDF
- 不收集用户个人信息
- 密码仅存储在用户本地，采用安全的存储机制

## 开发计划

1. **环境搭建**
   - 初始化Next.js项目
   - 配置Tailwind 4.X CSS
   - 设置Vercel部署

2. **基础功能开发**
   - 密码保护页面
   - PDF上传与预览
   - 转换为长图功能
   - 本地存储实现(密码状态、尾部图片缓存)
   - 当用户提交的 PDF 大于 5M 的时候，加一个逻辑思考判断，大于 30 页的时候仅展现前30 页。


3. **附加功能开发**
   - 尾部图片添加与缓存功能
   - 下载选项优化
   - UI/UX优化
   - PDF 大于 10MB 压缩至10M 以内

4. **测试与部署**
   - 功能测试
   - 性能优化
   - Vercel部署

## 设计规范

- **现代简约风格**：采用清晰、简约的界面设计
- **Tailwind设计系统**：遵循Tailwind设计原则，使用简洁的色彩方案和组件
- **响应式设计**：完美适配不同尺寸的设备和屏幕
- **交互反馈**：所有用户操作都有明确的视觉反馈
- **加载状态**：使用优雅的加载动画表示处理状态
- **直观的用户界面**：操作流程清晰，引导用户完成转换过程

## 使用指南

1. 访问网站，输入正确访问密码
2. 拖入PDF文件或点击上传
3. 自动开始转PDF
4. 可选择添加尾部图片，前端 UI 有功能组件
5. 生成长图等待用户下载
